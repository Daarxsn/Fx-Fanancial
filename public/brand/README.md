# Brand reference SVGs

These scalable SVGs are **visual reconstructions guided by the files supplied for Falchion Xeniaa**, not byte-for-byte or pixel-exact copies of the original logo pack/sample sheets.

- `falchion-xeniaa-logo.svg` — reconstructed company wing-mark and wordmark used in the shell and authentication UI.
- `myfx-pos.svg`, `fx-digitech.svg`, `fx-coworks.svg` — vector brand reference marks.
- `templates/myfx-pos-sample.svg`, `templates/digitech-sample.svg`, `templates/coworks-sample.svg` — editable invoice-layout references guided by the uploaded sample sheets. Each explicitly says not issued and uses placeholders instead of real company/tax/bank/customer data.

The uploaded brand guide specifies Gold `#DCAF51`, Saffron Red `#931314`, Charcoal `#111111`, Platinum `#F4F4F5`, and White `#FFFFFF`, with Sansation as the display face and Open Sans for UI/body. These font families are web-requested with system fallbacks; deployment owners must approve external font delivery or provide licensed self-hosted fonts.

Treat these as visual configuration guidance only. They do not represent active versioned template records or an issued PDF, and they must never be used to infer company/legal/tax/bank values.
